# DLMDSPWP01 — Programming with Python Assignment

This repository contains the complete implementation of the written assignment
for the module **DLMDSPWP01 — Programming with Python** (IU International
University of Applied Sciences).

## Purpose

The program identifies, for each of four noisy training functions, the ideal
function from a library of fifty noise-free reference functions that most
closely matches it. It then classifies a set of unlabelled test observations
against those four selected ideal functions, using a tolerance of √2.

## Repository structure

    data/       the three input datasets
    src/        the Python source code
    outputs/    figures produced by the code
    README.md   this file
    requirements.txt

## Requirements

Python 3.9 or later, with:

    pip install -r requirements.txt

## How to run

From the repository root:

    python src/exploratory_plots.py
